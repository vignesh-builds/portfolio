# Vignesh – Portfolio

Personal portfolio website.

- **frontend/** – React + Vite
- **backend/** – Spring Boot (contact form API)

## Run frontend
```
cd frontend
npm install
npm run dev
```

## Run backend
Set `DATABASE_JDBC_URL`, `DATABASE_USERNAME`, `DATABASE_PASSWORD` environment variables, then:
```
cd backend
./mvnw spring-boot:run
```
